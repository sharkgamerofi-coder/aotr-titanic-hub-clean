# AOTR Titanic Hub (Clean)

Script for **Attack on Titan Revolution** based on Titanic Hub (THUB1).

## What changed

- **Removed** the Discord webhook that logged your Roblox username, display name, user ID, place ID and platform.
- Optional troll message only (no personal data): `JODETE PUTO`.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/sharkgamerofi-coder/aotr-titanic-hub-clean/main/aotr-titanic-hub-clean.lua"))()
```
